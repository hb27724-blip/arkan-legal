# ARKAN — ملف العمل التجاري (Business Kit)

هذا المجلد يحتوي كل ما تحتاجه لتحويل تطبيق ARKAN من مشروع تقني إلى مشروع يدرّ دخلاً.

| الملف | شنو بيه |
|---|---|
| `01-target-customers.md` | مين العميل؟ القطاعات المستهدفة في العراق + وين تلگاهم بالضبط |
| `02-offer-and-pricing.md` | الباقات والأسعار وكيف تحسب قيمة العقد |
| `03-sales-script.md` | سكربت المكالمة والاجتماع + الرد على كل اعتراض متوقع |
| `04-outreach-templates.md` | قوالب جاهزة: واتساب، إيميل، لينكدإن، رسالة بعد الاجتماع |
| `05-content-30-days.md` | ٣٠ منشور جاهز للانستا/فيسبوك/تيك توك |
| `06-social-automation.md` | الطريقة الشرعية لأتمتة النشر (Meta + TikTok API) |
| `07-90-day-plan.md` | خطة ٩٠ يوم: من صفر إلى أول عميل يدفع |
| `prospects.csv` | جدول متابعة العملاء المحتملين — املأه وحدّثه أسبوعياً |

## القاعدة الذهبية
لا تبيع "تطبيق". بيع **نتيجة**: تقليل وقت التوقف، توثيق لا يمكن التلاعب به، وتقرير جاهز للإدارة.

## حالات العميل المحتمل في `prospects.csv`
`جديد` → `تم التواصل` → `مهتم` → `اجتماع محجوز` → `تجربة` → `عرض مرسل` → **`عقد`**
(أو: `مرفوض` / `بارد` — راجعه بعد ٣ أشهر)
